# prompt-library

Публичная библиотека промптов. Каждый промпт — это карточка метаданных, шаблон с
переменными, примеры входа и выхода, тест-кейсы и история версий. Формат рассчитан на
то, что промпт исполняет человек или агент, который не знает контекста автора.

## Каталог

| Промпт | Версия | Назначение | Статус |
|---|---|---|---|
| [`capture-page-to-file`](prompts/capture-page-to-file/card.yaml) | v1.0 | Страница, доступная автору, → автономный файл без потери скрытого контента | production-ready; TC2–TC3 не прогнаны |

## Структура

```
prompts/<slug>/
  card.yaml        название, версия, владелец, теги, цель, вход/выход, ссылки на примеры и тесты
  template.txt     шаблон с переменными
  examples/        input-01.md, output-01.md — пример входа и ожидаемого выхода
  tests/           tc1..tc3.md — тест-кейсы
CHANGELOG.md       история версий библиотеки
```

## Правила

- Изменение критериев приёмки — только через pull request и ревью владельца.
- Каждая версия получает запись в `CHANGELOG.md`; старые версии не перезаписываются.
- Тест-кейсы прогоняются до релиза, а не после. Результат прогона фиксируется в файле теста.
