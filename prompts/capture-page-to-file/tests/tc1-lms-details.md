# TC1 — урок LMS со свёрнутыми блоками

**Тип:** позитивный, основной. **Статус:** пройден 2026-11-20.

## Вход

Урок LMS: 11 разделов, 7 свёрнутых `<details>`, 7 видео с подписанными URL, CSS вшит
внутрь контентных блоков, блок задания продублирован виджетом формы.

## Ожидание

1. Все 11 заголовков разделов присутствуют в файле.
2. 7 медиа помечены счётчиком «видео N из 7», без ссылок.
3. Ноль строк, содержащих `padding`, `{`, `function`, `eyJ`.
4. Свёрнутые `<details>` присутствуют развёрнутым текстом.
5. Объём тела ≥ 90% текстового объёма корня.
6. Пересечение соседних разделов по тексту = 0 (дублей нет).

## Что показал прогон

Первый прогон провалил пункты 4 и 6: свёрнутые блоки слиплись в сплошной текст, задание
выведено дважды. После явного шага «раскрыть скрытое до конвертации» и шага «удалить
дубли» кейс пройден.
