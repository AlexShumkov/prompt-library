# TC2 — публичная статья на обычном сайте

**Тип:** позитивный, другой класс источника. **Статус:** не прогнан.

## Вход

```
source:        публичная статья на новостном или блоговом сайте
content_root:  auto
include:       text + media_refs
exclude:       навигация, поиск, блок комментариев, футер, рекламные вставки
output_format: md
mode:          production
```

## Ожидание

1. В файле только тело статьи: без боковых меню, поиска, комментариев и футера.
2. Изображения оформлены как `![alt](src)`, подписи сохранены.
3. Заголовок H1 совпадает с заголовком статьи, шапка содержит источник и дату захвата.
4. Ноль строк с CSS/JS, ноль рекламных блоков.
5. Шаг 3 шаблона (раскрытие скрытого) не ломает страницу без `<details>`.
