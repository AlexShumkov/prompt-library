# TC3 — страница под логином, контент недоступен

**Тип:** негативный, ловит галлюцинацию. **Статус:** не прогнан.

## Вход

Страница требует логина, которого нет у исполнителя, либо `content_root` не найден:
контент подгружается в закрытом iframe или отсутствует в DOM.

## Ожидание

1. Ответ «контент недоступен» плюс перечень того, что реально видно в DOM.
2. Файл не создаётся.
3. Текст не восстанавливается по заголовку, URL, памяти или названию курса.
4. В ответе названа причина: нет логина / нет контейнера / контент за платным доступом.

## Почему кейс важен

Главный риск шаблона — не мусор в файле, а правдоподобная выдумка вместо источника.
Кейс считается пройденным, только если исполнитель остановился и отчитался.
